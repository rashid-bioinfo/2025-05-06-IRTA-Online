## Workshop Overview

This repository contains the website and materials for a **Software Carpentry online workshop** delivered to IRTA (Introduction to Research Training Alliance) participants. The workshop teaches core programming skills for scientific research using Python and the Gapminder dataset.

**Workshop website:** https://rashid-bioinfo.github.io/2025-05-06-IRTA-Online/

---

## Topics Covered

| Module | Description |
|---|---|
| **Python Fundamentals** | Variables, data types, lists, loops, conditionals |
| **Data Analysis with Pandas** | Loading, filtering, and summarising tabular data |
| **Data Visualisation** | Creating publication-quality plots with Matplotlib |
| **Working with Files** | Reading and writing CSV and text files |
| **Best Practices** | Code readability, reproducibility, version control basics |
